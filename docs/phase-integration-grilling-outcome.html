Why composite-summed: one superstep, one shared ghost exchange per substage — vs N separate sweeps. Dissolves Lie/Strang ordering among the parabolic terms (summed, not sequenced).

Why Strang is ~free: substage count s ∝ √(dt/dt_par), so two half-supersteps of s/√2 stages total the same substage count as one full superstep — 2nd-order accuracy without doubling flux work.

Point-implicit stays outside: it is local (zero-stencil), so it must not be inflated by the STS substage count.

Stagnation caution: FLASH (the anchor) used full implicit. STS + nonlinear Sharma–Hammett + Spitzer κ∝T5/2 is where RKL monotonicity is unproven and cross-field leakage grows with s. Trigger to enable the implicit backend: leakage growth / s capping at stagnation.

The one new piece — SyncParabolicGhosts(bval, array)

RKL2 substeps run inside the operator, between the driver's normal boundary points, so the stencil needs a neighbour ghost refresh per substage. Today every ApplyBoundary does only a local single-block fill; the wired path FATALs on multi-block/MPI (hydro_tasks.cpp:437). Fix = bundle the existing InitRecv/PackAndSendCC/RecvAndUnpackCC/ClearRecv/ClearSend (+ Restrict/Prolongate) synchronously, exactly as CorrectFlux already bundles its flux routines. Not new infrastructure — a new caller of existing infrastructure.

Open risks & checkpoints

Nernst checkpoint

If 1–4 diverge from Ellison at the liner edge (B-transport / Tₑ–Tᵢ separation) → open extended-MHD epic.

Stagnation STS fragility

Cross-field leakage growing with s, or s capping → enable implicit backend (slot already reserved, ADR-0001/0009).

e_ion by subtraction

Difference of large numbers in cold fast regions (PRD-flagged). Measure-first; direct-evolution fallback only if noise appears.

Digitization fidelity

The rate-limiter on Phase C. Store each datum with source figure + DOI + method; tolerance includes digitization error.
